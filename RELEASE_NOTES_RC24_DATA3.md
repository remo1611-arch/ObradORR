# ObradORR 1.0.0-rc.25-data4

## Tipo de versión

DATA · Corrección conceptual trazada de platos finales recursivos.

## Cambios

- Corrección/refuerzo de 19 platos finales o duales que heredan subrecetas madre.
- Sin cambios de motor, interfaz de impresión ni arquitectura.
- Todas las fichas quedan como `pendiente`.
- Se añaden revisiones documentales `REV_RC25_DATA4_*` con `obrador_validation_required = 1`.

## Límite

No valida rendimientos, mermas, texturas, absorciones, reducciones, conservación ni aceptación organoléptica. Requiere prueba real de obrador.
