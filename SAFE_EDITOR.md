# SAFE_EDITOR · Edición segura

Se añade vista de impacto en el editor de fichas.

Muestra si la ficha está siendo usada como:
- subreceta culinaria;
- componente panadero/pastelero;
- base técnica de otra ficha.

Advertencia: cambiar ingredientes, rendimiento, APPCC o alérgenos de una ficha usada por otras puede alterar pedido consolidado, coste, alérgenos e impresión.

No se implementa todavía un bloqueo duro de edición; se evita una reescritura masiva del editor actual conforme a la regla del 30-40 %.
