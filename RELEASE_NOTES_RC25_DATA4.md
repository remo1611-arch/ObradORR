# ObradORR 1.0.0-rc.25-data4 · Panadería/pastelería puente

## Tipo de release

Release de datos. No modifica motor documental, impresión, CSS ni estructura funcional.

## Cambios principales

- Normalización conceptual de 13 fichas de panadería/pastelería ubicadas en `culinary_recipes`.
- Refuerzo de procesos técnicos: panificación directa, masas saladas, bizcochos, hojaldre, pasta quebrada, almíbar, compota y merengues.
- Corrección conceptual de `Almíbar 30 °Brix`: fórmula orientativa 300 g azúcar / 700 g agua y obligación documental de refractómetro para declarar Brix real.
- Conservación de todas las fichas como `pendiente`.
- Registro documental `REV_RC25_DATA4_*` con validación de obrador requerida.

## Estado

Apta para prueba funcional y revisión docente. No es validación de obrador.
