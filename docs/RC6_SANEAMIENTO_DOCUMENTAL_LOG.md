# RC6 · Saneamiento documental acumulado

Versión: ObradORR 1.0.0-rc.6

## Alcance

Corrección documental acumulada a partir de los Lotes 1A, 1B y 2.

No se han inventado datos de obrador: pesos cocidos, mermas, absorción de aceite, tiempos, temperaturas, madurez de masa madre, Bloom de gelatina ni datos de proveedor.

## Decisiones principales

- Las fichas no aptas permanecen bloqueadas o claramente advertidas.
- Las fichas pendientes muestran aviso en vista e impresión.
- Las panaderas con `yield_status = pending` muestran rendimiento pendiente.
- Prefermentos y masas madre `pending` se muestran como pendientes.
- Pan gallego se rotula como versión docente no IGP cuando no hay acreditación de pliego.
- El aceite de fritura se documenta como medio de fritura/pedido, no como rendimiento comestible íntegro.
- Gelatina con pescado pendiente queda separada del APPCC de pescado cocinado.
- Pan integral sin gluten con semillas mantiene advertencia de contacto cruzado, no gluten incorporado.

## Estado

Release candidate, no estable final.
