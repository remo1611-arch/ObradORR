# Perfiles documentales

- Aula-taller: documento operativo para alumnado.
- FPB: salida compacta y guiada.
- CM: ficha técnica de producción básica/media.
- GS: producción con costes, pedido y control técnico.
- Docente: salida completa de trabajo.
- Pedido: documento operativo de compra/producción.
- Auditoría: trazabilidad completa, costes, subrecetas y comprobación documental previa.
