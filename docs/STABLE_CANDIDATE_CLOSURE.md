# Cierre técnico · ObradORR 2.0.0 STABLE-CANDIDATE

## Decisión

RC3.1 se considera base suficiente para cerrar una candidata estable de ObradORR 2.0.0.

## Criterios cumplidos

- Nombre de documentos con ISO y segundos.
- Fecha visible en español con coma.
- Foto de cabecera a la derecha.
- APPCC breve compacto.
- Perfiles diferenciados.
- Pedido consolidado recursivo.
- Preflight no invasivo en perfiles de aula.
- Backup/import/export conservados.
- Ninguna ficha activa marcada como validada.

## Pendiente fuera de software

DATA8: prueba real de obrador para rendimientos, mermas, gramajes, tiempos, texturas y validación docente.
