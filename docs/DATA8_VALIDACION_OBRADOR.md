# DATA8 · Validación de obrador

La validación real corresponde al profesorado en aula-taller.

Para validar una ficha se debe registrar:

- fecha y responsable;
- cantidad formulada;
- cantidad elaborada;
- peso final;
- raciones/piezas obtenidas;
- merma;
- incidencias;
- textura/punto;
- conservación/servicio;
- decisión docente.

Hasta entonces, las fichas permanecen como propuestas documentales pendientes de validación real.
