# ObradORR 2.1.0-RC8 · Help Guide Final

Cambio limitado de interfaz:

- Añadida guía de uso plegable en la pestaña Inicio.
- La guía explica el flujo recomendado y las funciones principales: Sesión actual, Sesiones guardadas, Elaboraciones, Ingredientes, Validación de obrador, Sistema y copias, Exportaciones técnicas y consejos de seguridad.
- No se modifica SQLite, recetas, ingredientes, APPCC, alérgenos, costes, impresión ni exportaciones.

Criterio documental mantenido:

- Las fichas nuevas o modificadas siguen siendo propuestas documentales.
- La validación real corresponde al profesorado tras prueba de obrador.
- Excel/CSV/JSON se mantienen como salidas de auditoría y revisión, no como formatos maestros de edición.
