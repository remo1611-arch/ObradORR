# ObradORR 2.1.0-RC8 · Refinamiento HTML/UX

Parche limitado a interfaz y comodidad de edición.

## Alcance

- No se modifica `db/obradorr.sqlite`.
- No se modifican recetas, ingredientes, APPCC, alérgenos, costes ni validaciones.
- No se toca el motor de impresión PDF.
- No se recupera la importación Excel.

## Cambios

- Editor de elaboraciones más ancho y con aviso de edición cómoda.
- Editor de ingredientes en modal amplio con bloque de alérgenos separado.
- Campos largos autoexpandibles.
- Notas técnicas de líneas de receta en textarea.
- Tablas de edición y tabla de ingredientes adaptadas a tarjetas en móvil.
- Etiqueta principal de la pestaña de documentos cerrada como “Sesión actual”.
