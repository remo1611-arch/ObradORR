# Excel en ObradORR 2.1-RC7

## Estado actual

- `Catálogo Excel`: se mantiene como exportación técnica de consulta y auditoría.
- La plantilla Excel y la importación desde Excel quedan retiradas de la interfaz y del cargador principal.

## Criterio documental

SQLite sigue siendo la fuente de verdad. El Excel no es formato maestro de edición ni vía ordinaria para crear o modificar recetas.

## Para ampliar catálogo

La ampliación debe realizarse mediante la aplicación o mediante parche SQLite controlado, con fichas como `pendiente` y sin validación de obrador automática.
