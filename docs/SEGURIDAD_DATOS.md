# Seguridad de datos

ObradORR guarda una copia local en IndexedDB del navegador y permite descargar copias SQLite completas.

Recomendaciones:

- En PC: usa guardado local y descarga SQLite para copias importantes.
- En móvil/Termux: descarga SQLite al final de cada sesión importante.
- Para mover datos entre dispositivos: descarga SQLite e importa en el otro dispositivo.
- Para compartir con otro docente: usa SQLite o práctica ZIP.
- Para combinar sin machacar datos: usa `Importar y combinar SQLite`.

La recuperación local depende de navegador, dispositivo y puerto/origen.
