# Guía Windows

1. Descomprime el ZIP.
2. Abre PowerShell en la carpeta raíz del proyecto.
3. Ejecuta:

```powershell
python -m http.server 8832 --bind 127.0.0.1
```

4. Abre:

```text
http://127.0.0.1:8832/app/obradorr.html?v=obradorr-200-public-github-ready
```

No abras `app/obradorr.html` con `file://`.
