# Selección e impresión

ObradORR permite preparar documentos de aula, auditoría y pedido desde la pestaña **Imprimir / exportar**.

## Listados

Los listados se cargan de forma progresiva para mantener buen rendimiento en móvil y PC:

- **Mostrar más** añade otro bloque de resultados.
- **Mostrar todas** muestra todos los resultados actuales.
- Si hay búsqueda activa, **Mostrar todas** se aplica a los resultados filtrados.

## Añadir una elaboración

Al añadir una elaboración individual se solicita la cantidad:

- Fichas ordinarias: raciones o rendimiento.
- Formulación: piezas con peso unitario, masa total o harina total.

Las piezas de formulación siempre requieren peso unitario para evitar escalados ambiguos.

## Añadir varias elaboraciones

En **Imprimir / exportar** se mantiene una única acción masiva:

- **Añadir todo el catálogo**, con confirmación previa.

Para añadir elaboraciones concretas se usa el botón **Añadir** de cada ficha, que solicita cantidad/modo de cálculo antes de incorporar la elaboración a la selección. Las cantidades pueden revisarse después en la selección antes de imprimir o exportar.

## Campos docentes

Los campos de práctica, responsable y observaciones incluyen ejemplos de ayuda bajo el campo. Esos ejemplos son solo orientativos: no se guardan, no se exportan y no se imprimen salvo que el usuario escriba texto real.
