# ObradORR 1.0.0-rc.13

Release candidate documental para iniciar la **Vía B · contraste bibliográfico/normativo**.

## Objetivo

Preparar ObradORR para documentar cada ficha como propuesta técnica contrastable, sin declarar ninguna como validada hasta que exista prueba real de obrador.

## Cambios

- Nueva estructura SQLite de auditoría documental por fuentes.
- Registro inicial de fuentes marco: normativa alimentaria, APPCC, anisakis, cocina profesional, pastelería, panadería y panificación.
- Aviso visible en impresión: el contraste bibliográfico no equivale a validación de aula.
- Documentos nuevos:
  - `docs/RC13_VIA_B_AUDITORIA_DOCUMENTAL_LOG.md`
  - `docs/AUDITORIA_DOCUMENTAL_FUENTES.md`
- Metadatos actualizados a `1.0.0-rc.13`.

## Política de validación

- `pendiente`: propuesta documental, no validada en obrador.
- `no_apta`: bloqueada o no defendible hasta corrección.
- `validada`: reservada a prueba real de obrador documentada.

## Límites

No se han validado rendimientos, mermas, puntos de cocción, fermentaciones, absorciones de aceite ni vida útil. La RC13 no reformula fichas; prepara la trazabilidad de fuentes.
