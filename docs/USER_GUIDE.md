# USER_GUIDE · ObradORR 1.0.0-rc.3

## Flujo docente básico

1. Abrir la app con servidor local.
2. Entrar en Elaboraciones.
3. Buscar fichas.
4. Añadir a práctica.
5. Ajustar raciones, piezas o harina.
6. Entrar en Imprimir / exportar.
7. Generar fichas, pedido o fichas + pedido.
8. Guardar sesión si se va a reutilizar.
9. Descargar copia SQLite desde Sistema si se quiere conservar el trabajo.

## Edición

La edición está organizada de forma progresiva:

- Datos de ficha.
- Ingredientes o fórmula.
- Prefermento.
- Pasos técnicos.
- Componentes elaborados.
- Ingredientes y alérgenos desde la pestaña Ingredientes.

No se muestran IDs técnicos como operación normal de aula.
