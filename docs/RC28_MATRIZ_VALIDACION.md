# RC28 · Matriz mínima de validación manual

## Arranque

- [ ] Abrir en Windows.
- [ ] Abrir en Termux.
- [ ] Confirmar que no aparece aviso de versión/caché incompatible.
- [ ] Confirmar que la app carga elaboraciones.

## Fichas recomendadas

- [ ] Tarta San Marcos.
- [ ] Almíbar 30 °Brix orientativo para calar.
- [ ] Fumet de pescado clásico.
- [ ] Salsa brava.
- [ ] Patatas bravas.
- [ ] Pad thai de langostinos.
- [ ] Quiche lorraine.
- [ ] Pan gallego.
- [ ] Hojaldre base.
- [ ] Una ficha real de `bakery_recipes` con prefermento o masa enriquecida.

## Salidas documentales

- [ ] Ficha simple.
- [ ] Ficha con subrecetas.
- [ ] Pedido consolidado.
- [ ] Ficha + pedido.
- [ ] Perfil aula-taller.
- [ ] Perfil docente.
- [ ] Perfil auditoría.
- [ ] PDF desde navegador.

## Criterios de aceptación

- [ ] No hay fichas activas como `validada`.
- [ ] El pedido consolida subrecetas.
- [ ] El almíbar escala por cantidad solicitada.
- [ ] APPCC/alérgenos aparecen sin bloques rotos.
- [ ] No hay cortes de página que pisen texto.
- [ ] Las tablas son legibles.
- [ ] No aparece contenido interno de depuración en la salida docente.
