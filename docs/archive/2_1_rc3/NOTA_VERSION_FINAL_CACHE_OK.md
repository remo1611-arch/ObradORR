# Nota de empaquetado final

Este paquete recompone la versión pública final con nombre diferenciado para evitar descargas antiguas en navegador/Android.

Debe cargar módulos con:

`?v=obradorr-210-rc7-release-candidate`

Y validar:

- `cache_tag = obradorr-210-rc7-release-candidate`
- sin `Masa/pasta total`
- sin `masa/pasta cruda`
- con `Masa total`
- con `Piezas + peso unitario`
- con `Harina total`
