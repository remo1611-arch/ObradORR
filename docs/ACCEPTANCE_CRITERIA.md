# ACCEPTANCE_CRITERIA · ObradORR 1.0.0-rc.3

## Bloqueantes

- [✓] La app debe arrancar desde `app/obradorr.html` con servidor local.
- [✓] No debe usar `window.open`.
- [✓] Debe imprimir por iframe.
- [✓] SQLite debe superar `PRAGMA integrity_check`.
- [✓] SQLite debe superar `PRAGMA foreign_key_check`.
- [✓] Torta de nata no puede contener Nata 35 % MG = 0 g ni Azúcar blanco = 0 g en vista de fórmula.
- [✓] Deben existir componentes panaderos/pasteleros semilla.
- [✓] Debe haber registro `schema_migrations`.
- [✓] Los JS principales deben superar `node --check`.
