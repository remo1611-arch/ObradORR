# RC9 · Release Candidate

Ajuste final de UX en la apertura de la vista de impresión independiente.

## Criterio aplicado

- Si `print-view.html` se abre correctamente, no se muestra modal bloqueante en la app principal.
- Si el navegador bloquea la pestaña nueva, se muestra un modal con el botón `Abrir vista independiente`.
- El visor integrado clásico sigue retirado de la interfaz.

## Alcance

No se modifican SQLite, recetas, ingredientes, costes, alérgenos, APPCC, modelos documentales ni CSS profundo de impresión.
