# PRINT_BLOCK_MATRIX_RC9_C

Documento técnico de cobertura para RC9-C.

## Decisiones

- Los modelos de impresión se nombran por finalidad documental, no por etapa, ciclo o nivel.
- La matriz de bloques es declarativa y queda lista para ser consumida por un futuro `print-view.html`.
- Los ajustes avanzados no sustituyen al modelo; solo lo sobrescriben para una salida puntual.
- El pedido se trata como `Pedido de producción`, documento operativo de aprovisionamiento/mise en place.

## Próxima fase prevista

RC9-E debería extraer el render en secciones imprimibles más independientes, utilizando `printBlocks` como contrato documental.
