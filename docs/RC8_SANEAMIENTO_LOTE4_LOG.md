# RC8 · Saneamiento documental del Lote 4

Aplicado sobre ObradORR 1.0.0-rc.7.

## Alcance

- Masas enriquecidas: aviso de TFM, fermentación, cocción, peso cocido, merma y conservación pendientes.
- Laminados: aviso de mantequilla de vueltas, pliegues, reposos, grosor, fermentación final, cocción, peso cocido y merma pendientes.
- Variantes refrigeradas: aviso de separación entre ficha base y relleno/nata/crema.
- Pain au chocolat: proveedor/alérgenos de chocolate pendientes.
- Hojaldre fermentado: documentado como masa laminada fermentada.
- Challah: grasa actual verificada como aceite; posible variante docente si se sustituyera por mantequilla/lácteo.

## No aplicado

No se validan fórmulas, pesos, mermas, tiempos, temperaturas, pliegues, reposos, grosor ni datos de proveedor.
