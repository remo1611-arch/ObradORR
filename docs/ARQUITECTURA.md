# Arquitectura

Aplicación web local/offline basada en HTML, CSS, JavaScript y SQLite WASM.

Capas principales:

1. Base SQLite incluida.
2. Modelo documental normalizado.
3. Motor recursivo para pedido, costes y alérgenos.
4. Perfiles documentales.
5. Comprobación documental previa.
6. Renderizado HTML/PDF mediante navegador.
7. Exportaciones y copias de seguridad.
