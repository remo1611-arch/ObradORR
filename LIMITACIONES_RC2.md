# Limitaciones RC2

- La escritura directa en carpeta depende de la compatibilidad del navegador con File System Access API.
- La importación combinada está diseñada para no sobreescribir; no reemplaza registros existentes en RC2.
- Las fotos se remaquetan como cabecera adaptativa, pero no se edita ni comprime el archivo de imagen.
- La fecha española se aplica a documentos imprimibles; los nombres de archivo mantienen ISO seguro.
- No se realiza validación real de obrador.
