# Guía Windows · ObradORR 2.0.0

1. Descomprime `ObradORR_2_0_0_PUBLIC_RELEASE.zip`.
2. Abre PowerShell o Terminal en la carpeta descomprimida.
3. Ejecuta:

```powershell
python -m http.server 8835 --bind 127.0.0.1
```

4. Abre en el navegador:

```text
http://127.0.0.1:8835/app/obradorr.html?v=obradorr-200-public-release-final-ui-hints
```

Reset local:

```text
http://127.0.0.1:8835/app/reset_local_data.html?v=obradorr-200-public-release-final-ui-hints-reset
```
