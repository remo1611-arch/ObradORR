# Limitaciones · ObradORR 2.0.0 STABLE-CANDIDATE

1. **Validación gastronómica**: las fichas son propuestas documentales contrastadas, no fichas validadas en obrador.
2. **Rendimientos**: cualquier rendimiento, merma o peso cocido debe comprobarse en aula-taller.
3. **Importación**: la combinación de bases está pensada para bases ObradORR compatibles o próximas. No es migrador universal de bases antiguas.
4. **PDF**: el nombre sugerido y los cortes de página dependen parcialmente del navegador.
5. **File System Access API**: escoger carpeta de backup puede no estar disponible en todos los navegadores/dispositivos; existe fallback de descarga.
6. **Fotos**: se respetan proporciones con `object-fit: contain`; algunas imágenes pueden dejar aire si su formato es muy extremo.
