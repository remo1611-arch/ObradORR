# Limitaciones RC3

- El nombre final del PDF puede depender del navegador y del diálogo de impresión.
- La maquetación se mejora con CSS print, pero los motores de impresión de Firefox/Chrome/Android pueden variar.
- No se reescribe el motor PDF completo.
- No se tocan fórmulas, rendimientos ni validación de obrador.
- Backup, importación y exportaciones de RC2 se conservan sin rediseño.
